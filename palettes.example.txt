; 示例色板文件。复制一份改名为 palettes_v1.txt 后即可被工具读取。
; 以 > 开头的是一个色板的名字，下一行写颜色，用逗号分隔，# 号可省略。
; 一个色板可以写多行，会自动接续。分号开头的行是注释。
;
; 颜色后面可以加 @透明度（0-100），例如：
;   #2E5A88        完全不透明
;   #2E5A88@50     50% 透明
;
; 例：
; >Nature配色
; #1B9E77,#D95F02,#7570B3
; >半透明标注
; #2E5A88@60,#D55E00@30
